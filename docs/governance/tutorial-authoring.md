# 教程作者规范

本文件定义 `docs/tutorials/` 版本课程的写作与验收要求。教程是可独立学习、运行和验证的课程，不是版本更新摘要；代码与测试是事实来源，计划文档只描述意图。

## 内容原则

- 每课只讲当前版本相对上一版本新增的核心概念，并提供 `git checkout` / `git diff` 入口；不要提前描述后续版本行为。
- 每课必须在开头声明唯一代码快照 tag、相邻差异基线和示例命令适用的 shell。补丁内容必须单独声明补丁 tag 与基线。
- 先解释上一版的限制和本版要解决的问题，再解释实现、关键取舍及边界。
- 默认值、调用顺序、失败路径、返回值、配置项和命令必须与对应 tag 的实现一致。
- 突出一个教学主线；代码片段保持最小，完整实现使用 `https://github.com/liiiiiiiiil/agent-from-scratch/blob/<tag>/<path>` 固定链接，不链接默认分支或作者本机路径。
- 协议、安全、并发、预算、异常降级等主题要同时说明正常路径、不变量和刻意不解决的问题。

## 每课结构

原则上包含：版本/上下课导航；代码 tag 与相邻 diff 基线；目标；前置条件与 tag 切换；改动文件表和 `git diff --stat`；问题、概念、流程与数据结构；实现拆解；设计选择与边界；可运行示例；测试命令与验收点；本版特性、下一课预告和 tag 固定代码索引。确实不适用的章节可合并，但学习链路不能中断。

教程命令默认使用 Bash/zsh，并统一写成 `PYTHONPATH=src python ...`；PowerShell 等价写法只需在教程总览集中说明。带命令行参数的 CLI 调用称为“命令行首条任务”，不得暗示处理参数后进程立即退出。每课至少提供一条无需网络和真实 LLM 配置即可执行的标准库验收路径。

## 同步与验收

完成版本时同步 README（中英文）、教程索引、操作手册、CHANGELOG、`pyproject.toml` 版本信息，并检查链接、代码片段、命令、协议描述和测试覆盖。运行时文档示例优先使用仓库 API 与标准库；开发工具（如 pytest）应同时给出仓库原生 smoke test 方式。

`scripts/check_tutorials.py` 只检查教程结构与格式；`scripts/check_tutorial_facts.py` 使用本地 Git 对象检查版本/tag 映射、相邻基线和固定源码路径。提交教程前必须同时运行两者。
