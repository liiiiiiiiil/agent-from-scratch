# 主 README 编写规范

本文件规定仓库中文主 README（`README.md`）的定位、命名和同步要求。英文说明维护在 `README_EN.md`，不强制中文标题，但必须保持入口链接和版本信息一致。

## 定位与结构

- README 首屏说明项目是什么、适合谁、当前版本和阅读方式。
- 主体只保留快速开始、学习路径、项目结构、设计约束和文档入口；版本课程细节放在 `docs/tutorials/`，完整运行说明放在操作手册。
- 学习路径按“大阶段 → 版本小阶段”组织，版本表、教程索引、计划和 CHANGELOG 必须互相对应。
- 命令必须可复制，配置示例不得包含真实 `BASE_URL`、`API_KEY` 或 `MODEL`。

## 命名与文风

- 阶段名和版本主题优先使用通俗中文；必要的产品名、协议字段、代码标识和公认技术名词可保留英文，首次出现时给出中文含义。
- 标题保持短而具体，避免营销口号、同义词混用和只对维护者可读的内部简称。
- 说明先讲用户要完成的事情，再补充实现背景；不要在 README 中重复整篇教程。

## 更新与验收

新增版本时同步检查 `README.md`、`README_EN.md`、`docs/tutorials/README.md`、操作手册和 CHANGELOG 的版本、链接与状态。

提交前运行：

```bash
PYTHONPATH=src python scripts/check_readme.py
```
